zalgorithm について解説する。入力は文字列 S のみである。
次のように返される配列, dp を定義する。
dp[i]:= S と S[i,|S|) の最長共通接頭辞の長さ
i=0 の時の値は |S| である。
l<=k について計算できたとして、l=k+1 における dp[l] の値を得たいとしよう。
後述に示すが、dp[1]>=r であると確定しているという r の値も持っておくことにする。
最初、r=0 である。
dp[l] を正しく計算するには愚直に計算すれば良い。
ここで、dp[l] が確定したとする。dp[l]>0 であることを次で仮定する。
これは S[0,dp[l]) と S[l,dp[l]+l) が共通であることを示す。
したがって、次の事実が成立する。
0<i<dp[l] に対して、i+dp[i]<dp[l] -> dp[l+i]=dp[l] 
また、i=dp[l] に対してもある程度使い回すことができる。（下に参照）
これは明らかである。
したがって、次のようなコードは正当である。
template<class String>
vc<int>ZAlgorithm(String&s){
    int N=s.size();
    vc<int>dp(N);
    dp[0]=N;
    int l=1,r=0;
    while(l<N){
        while(l+r+1<N&&s[l+r+1]==s[r])++r;
        dp[l]=r;
        if(dp[l]==0)continue;
        int k=1;
        while(k+dp[k]<dp[l]&&l+k<N)dp[l+k]=dp[k],++k;
        l+=k,r-=k;
    }
    return dp;
}
計算量は O(N) である。　
l は l+=k でのみ増えることに注目すれば上は明らか。
