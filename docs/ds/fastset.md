# fast_set

`[0,n)` 上の整数集合を管理する高速 bitset 木です。
挿入、削除、存在判定、次要素・前要素探索ができます。

## コンストラクタ

### `fast_set(int n)`

宇宙集合を `[0,n)` として初期化します。

- 制約: `0<=n<=2^30`
- 計算量: `O(n)`

## メソッド

### `int fs.insert(int x)`

`x` を挿入します。
新しく入ったなら `1`、すでに存在したなら `0` を返します。

- 制約: `0<=x<n`
- 計算量: `O(log_64 n)`

### `int fs.erase(int x)`

`x` を削除します。
存在していたなら `1`、なければ `0` を返します。

- 制約: `0<=x<n`
- 計算量: `O(log_64 n)`

### `int fs.count(int x)`

`x` が存在すれば `1`、なければ `0` を返します。

- `x` が `[0,n)` の外なら `0`
- 計算量: `O(1)`

### `int fs.next(int x)`

`x` 以上の最小の要素を返します。
存在しなければ `n` を返します。

- `x<0` なら `0` 以上から、`x>=n` なら直ちに `n` を返します。
- 計算量: `O(log_64 n)`

### `int fs.prev(int x)`

`x` 以下の最大の要素を返します。
存在しなければ `-1` を返します。

- `x<0` なら直ちに `-1`、`x>=n` なら `n-1` 以下から探します。
- 計算量: `O(log_64 n)`

## メンバ

- `size`
  現在の集合サイズです。

  - 取得の計算量: `O(1)`

## 境界・注意

- 値域は `[0,n)` です。
- 返り値 `n` と `-1` は番兵として使います。
- 内部の 64 進階層は 5 桁固定です。`int` で安全に扱える上限として `n<=64^5=2^30` を満たしてください。

## 計算量

`insert` / `erase` / `next` / `prev` は `O(log_64 n)`、`count` と `size` は `O(1)` です。使用メモリは `O(n)` です。

## 使用例

```cpp
#include "ds/ordered/fastset.hpp"

fast_set fs(n);
fs.insert(3);
fs.insert(10);

int a=fs.next(4);  // 10
int b=fs.prev(9);  // 3
```
