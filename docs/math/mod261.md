# mod261_int

`2^61-1` を法とする modint です。
ローリングハッシュなどで使いやすい型です。

## 型

### `mod261_int`

法は固定で `2^61-1` です。

## 主なメソッド

### `mod261_int(ll x)`
### `static mod261_int raw(ll v)`
### `mod261_int pow(uint64_t n) const`
### `mod261_int inv() const`

## 演算

- `+`, `-`, `*`, `/`
- `+=`, `-=`, `*=`, `/=`
- `==`, `!=`
- 入出力演算子

## 境界・注意

- 法は固定です。
- `inv()` は `pow(mod-2)` で実装されています。

## 使用例

```cpp
#include "math/modular/mod261.hpp"

mod261_int a=123,b=456;
auto c=a*b+a.pow(10);
```
