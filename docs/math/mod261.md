# Mod261Int

`2^61-1` を法とする modint です。
ローリングハッシュなどで使いやすい型です。

## 型

### `Mod261Int`

法は固定で `2^61-1` です。

## 主なメソッド

### `Mod261Int(ll x)`
### `static Mod261Int raw(ll v)`
### `Mod261Int pow(uint64_t n) const`
### `Mod261Int inv() const`

## 演算

- `+`, `-`, `*`, `/`
- `+=`, `-=`, `*=`, `/=`
- `==`, `!=`
- 入出力演算子

## 境界・注意

- 法は固定です。
- `inv()` は `pow(mod-2)` で実装されています。

## 使用例

```cpp
#include "math/mod261.hpp"

Mod261Int a=123,b=456;
auto c=a*b+a.pow(10);
```
