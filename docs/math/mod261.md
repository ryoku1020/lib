# mod261_int

`2^61-1` を法とする modint です。
ローリングハッシュなどで使いやすい型です。

## 型

### `mod261_int`

法は固定で `2^61-1` です。

## 主なメソッド

### `mod261_int(ll x)`

`x` を法で正規化して構築します。負数も使用できます。

### `static mod261_int raw(ll v)`

正規化済みの `0 <= v < 2^61-1` をそのまま格納します。

### `mod261_int pow(uint64_t n) const`

`n` 乗を返します。

### `mod261_int inv() const`

乗法逆元を返します。

## 演算

- `+`, `-`, `*`, `/`
- `+=`, `-=`, `*=`, `/=`
- `==`, `!=`
- 入出力演算子

## 計算量

- 四則演算、比較、構築、`raw`: `O(1)`
- `pow(n)`: `O(log n)`
- `inv()` と `/`: 61 bit 固定法に対する二分累乗なので `O(log mod)`（この型では実質 `O(1)`）
- 追加メモリ: `O(1)`

## 境界・注意

- 法は素数 `2^61-1` に固定されています。
- `raw(v)` は `0 <= v < mod` のときだけ使えます。実装の `assert` は `v >= 0` しか検査しません。
- `inv()` は `pow(mod-2)` で実装されているため、0 の逆元はありません。0 で割ってはいけません。
- 乗算は 61 bit 法向けにオーバーフローを避けて実装されていますが、`raw` で範囲外の値を入れるとこの前提が崩れます。

## 使用例

```cpp
#include "math/modular/mod261.hpp"

mod261_int a=123,b=456;
auto c=a*b+a.pow(10);
cout<<c<<"\n";
```
