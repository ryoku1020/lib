# AHU Algorithm

根付き木の同型判定用エンコードを返す関数です。
同型な根付き木は同じ括弧列表現になります。

> **注意**: この実装は `.not_lib` 配下の試験コードです。現在の `tree` API とは互換性がなく、そのままではコンパイルできません。以下は実装が意図している API の説明です。

## 関数

### `string ahu(const Tree& tree_, int root)`

木 `tree_` を `root` で根付き木とみなし、その構造を表す文字列を返します。

## 計算量

意図されているアルゴリズムでは、頂点数を `N` として時間 `O(N)`、返り値と作業領域に `O(N)` です。同じ深さの部分木列をバケットソートし、内部の SA-IS も列長に対して線形時間で構築します。

## 境界・注意

- 内部で suffix array を使って子部分木の順序を決定しています。
- 現在の実装は未定義の `Tree` 型と旧コンストラクタを参照しており、利用可能なライブラリ API ではありません。
- `0 <= root < N` が必要です。
- 入力は連結かつ閉路のない木を前提とします。
- 根付き木として比較します。同じ無根木でも根を変えると表現が変わることがあります。

## 使用例

意図されている呼び出し方は次の形です。現在の実装では動作例としてコンパイルできません。

```cpp
#include ".not_lib/tree/ahu.hpp"

string s1=ahu(tree1,r1);
string s2=ahu(tree2,r2);
bool iso=(s1==s2);
```
